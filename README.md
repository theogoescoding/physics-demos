# GCSE Physics Demos (AQA 8463)

Interactive physics demonstrations for an interactive whiteboard or projector. The whole app is one file, `physics-demos.html`. It needs no internet connection and nothing to install.

## Opening the app

1. Double-click `physics-demos.html`. It opens in your default browser (Chrome, Edge or Firefox).
2. Click a tile on the home screen. The tiles are grouped by topic: Energy, Electricity, Magnetism, Waves, Forces, Matter, Radioactivity, Motion.
3. Press **⛶ Full screen** for projecting. Use **A− / A+** to change the text size, and **☾ Dark** to switch to a dark background. The browser remembers both choices.

On a laptop-width screen (narrower than 1500 pixels) the header buttons shrink to their icons (☾, ⛶) to keep the header on one line. Hover over a button to see its name.

You can copy the file onto a USB stick or another computer: it works wherever it's opened.

## The experiment screen

Each experiment screen has three parts, and everything you need to run the experiment fits on one screen without scrolling.

| Part | What's in it |
|---|---|
| **Left: run the experiment** | Predict, Compare and Ideal / Realistic at the top, then the diagram, the run buttons, every slider, drop-down and switch, and the **Show:** overlay buttons |
| **Middle: results** | The graph (with its tabs), the equation, the live values, and **＋ Record reading** with a count of the readings so far |
| **Right edge: the sidebar** | A column of five buttons that open extra panels (see below) |

The diagram grows and shrinks to fill the space the controls leave, so experiments with more controls have a slightly shorter diagram.

Each slider shows its value. Its range (for example 0 to 20 N) appears when you hover over it. In earlier versions it was printed underneath.

### The sidebar

The five buttons down the right-hand edge each open one panel:

| Button | Panel |
|---|---|
| **x = Variables** | Each equation with what every symbol means and its unit |
| **💡 Key idea** | The main idea in one paragraph |
| **⚠ Common mistake** | A common misconception and why it's wrong |
| **≈ Assumptions** | What the simulation simplifies |
| **▦ Data table** | The results table, with Undo, Clear, Copy table and Download CSV |

- Click a button to open its panel; click it again (or the panel's **×**) to close it.
- You can open as many panels as you like at once. They stack over the graph, and the column scrolls if they don't all fit.
- All panels start closed each time you open an experiment, so the graph and the equation are what the class sees first.

### Controls on every experiment

| Control | What it does |
|---|---|
| Run button, ⏭ Step, ↺ Reset | Run or pause, move on one step, back to the start. Many experiments rename the run button (for example **Switch heater on**, **Sweep**, **Let go of the beam**) |
| Speed | ¼× to 5× |
| ❓ Predict | Full-screen question with a hidden answer. **Set it up and close** sets the simulation up so the class can test their prediction |
| ⇆ Compare | Two set-ups side by side (where it makes sense) |
| Ideal / Realistic | Switches between a simplified version and a more realistic one. A short note explains the difference |
| Show: … | Turns arrows, values, equations and graph extras on or off |
| Dashed circles on the diagram | Things you can drag or click |
| ＋ Record reading | Adds a row to the results table (open **▦ Data table** in the sidebar to see it). From the table, **Copy table** pastes into Excel or Word and **Download CSV** saves a file. Suggested units and significant figures are shown above each table |
| 🖨 Print worksheet | Opens the worksheet selection screen (see below) |

Keyboard shortcuts: **Space** start/pause, **S** step, **R** reset, **P** predict, **Esc** close the pop-up.

## Printing a student worksheet

Press **🖨 Print worksheet** (shown as **🖨 Worksheet** on a laptop) on any experiment. A selection screen opens with a live preview of the printout on the right.

**Always included** (cannot be removed):
- title, topic and AQA reference
- name, class and date boxes
- aim
- method as short numbered steps
- variables table: independent, dependent and control. Students write in the variables; the suggested units are printed.
- equation with blanks to fill in, plus a table of its symbols, quantities and units
- assumptions
- results table: headings with units, and blank rows
- graph area: blank 2 mm graph paper with labelled axes and units

**Add-ons** (tick or untick each one; **Predict** and **Evaluation** are ticked to start with):

| Add-on | What it adds |
|---|---|
| Predict | A question to answer before the experiment, with space for a prediction and a reason |
| Graph-reading questions | Two or three questions on the gradient, intercept or area of the graph. For infrared radiation, which uses a bar chart, the questions are about reading the bar chart |
| Worked example | A calculation with the first steps shown and the last step left for students |
| Key idea box | The Key idea from the app |
| Common mistake question | “Which of these statements is true?” with four tick boxes |
| Evaluation | Prompts about uncertainty, anomalous results and improvements, with writing lines |

Your ticks are kept while the page is open, so you can print several experiments with the same choices.

**Checking before you print.** Use **Preview: Student worksheet / Answer key** to switch between the two documents. The number of pages each will print is shown next to the switch. Most worksheets are 3 pages with the default add-ons, and 4 with every add-on.

**Teacher answer key.** **🖨 Print answer key** prints a separate document. It contains the answers to every blank and question on the worksheet you have chosen: the variables, the completed equations, what the results and graph should show, and answers for each ticked add-on. Every page is headed **TEACHER ANSWER KEY**. It prints on its own, so it never ends up in a pile of student copies.

**Print settings.** The worksheet always prints in black and white on A4 portrait, with its own page numbers in the footer of every page. Sections are never split across pages. In the print window:
- choose your printer, or **Save as PDF**
- leave **Scale** at 100% (default)
- **Background graphics** can stay off; the worksheet doesn't need it
- in Firefox, untick **Print headers and footers** if the browser adds its own

The worksheet describes the real class practical, not the simulation. Its text is in section **3b. WORKSHEET TEXT** of the file (see "Changing the settings").

## What's simplified (also shown on screen in the ≈ Assumptions panel)

**Energy**
- **Specific heat capacity:** the block is the same temperature throughout, and the heater power is constant.
  - Ideal: no losses.
  - Realistic: the heater warms up first, and energy is lost to the room in proportion to the temperature difference, so the calculated c comes out too big.
  - Runs 20× faster than real time.
- **Thermal insulation:** each material has typical rates for conduction, convection and radiation. More layers slow conduction; a lid cuts convection and evaporation.
  - Ideal: Newton's law of cooling.
  - Realistic: adds evaporation, T⁴ radiation, and readings to 0.5 °C.
  - Runs 30× faster than real time.
- **Efficiency:** devices have typical steady powers. All wasted energy ends up warming about 60 kg of air in the room.

**Electricity**
- **I–V and circuits:** see the earlier notes. Ideal meters, a model lamp and diode, and bulbs treated as 12 Ω resistors.
- **Resistance of a wire:** a uniform wire with a 2 Ω protective resistor in series. Realistic mode adds 0.15 Ω contact resistance at the clips (so the R–L line misses the origin), wire heating (mainly copper), and meter resolution.

**Magnetism**
- **Motor effect:** a uniform field at right angles to the wire, which is seen end-on (⊙ out of the screen, ⊗ into it).
- **Induction:** a simple model of the magnet's field through the coil, using Faraday's law (not needed for GCSE). The voltmeter is centre-zero.

**Waves**
- **Infrared:** "emitting ability" values are matt black 0.95, shiny black 0.88, matt white 0.84 and shiny silver 0.05. Real white paint emits infrared almost as well as black paint; this is noted on screen. Absorption plates heat up according to the same values, with wax melting at 50 °C. The absorption test runs 10× faster.
- **Ripple tank:** waves travel at 0.30 m/s in deep water and 0.18 m/s in shallow water, whatever the frequency. Bright lines are crests.
- **String:** μ = 2 g/m and tension = m g. The vibration is shown slowed right down. Travelling-wave mode assumes the far end absorbs the wave.

**Forces**
- **Momentum:** a straight, level track, with bumpers that push for 0.06 s. Right is positive. Realistic mode adds rolling friction (an external force).
- **Moments:** the beam is weightless with the pivot in the middle. Realistic mode adds pivot friction.
- **Pressure:** the liquid's density is uniform. Realistic mode adds atmospheric pressure (101 000 Pa). Water-jet speeds follow from the pressure at each hole, ignoring air resistance.

**Matter**
- **Density:** 1 cm³ of water has a mass of 1 g. Realistic mode reads the balance to 0.1 g, the cylinder to 1 cm³ and the ruler to 1 mm, and a floating object displaces only its own mass of water unless you push it under.

## Changing the settings

- **`1. SETTINGS`**: g and air density, and `ROOM_TEMP` (room temperature).
- **`DEFAULTS`** and **`CONTROLS`** inside each experiment: starting values and slider ranges (`min`, `max`, `step`, `unit`).

- **`3b. WORKSHEET TEXT`**: everything the printed worksheet says, one block per experiment (for example `fma: { ... }`). The comment at the top of the section explains each part:

## Adding a new experiment

Every experiment is one `register({ ... })` block in section **3. EXPERIMENTS**. Its `topic` decides which group it appears in on the home screen.

1. Copy an existing block that is closest to what you want. "Forces and acceleration" (`id: 'fma'`) is the simplest template.
2. Change `id`, `topic` (one of the eight topics), `title`, `equationShort` and `rp`.
3. Fill in the parts. The comment at the top of section 3 explains each one:
   - `defaults`, `controls`: the settings and sliders
   - `reset()`, `step(dt)`, `finished()`: the simulation. Put the equations in `Object.assign(Physics, {...})`, where the self-test can check them
   - `drawDiagram(ctx, w, h, C)`: draws the apparatus. Helpers: `arrow()`, `wavyArrow()`, `label()`, `addHandle()` for draggable or clickable things, and `Circuit.*` for circuit symbols
   - `drawGraph(canvas, id, C)`: calls `plot()` with lines, points, bars or shading (or two graphs in one canvas)
   - `readouts()`, `record()` and `table.columns`: the numbers on screen and in the results table
   - Optional extras (`runLabels`, `clock()`, `settled()`, `stepSize`, `beforeRun()`, `onParam()`) are listed in the same comment
4. Add a worksheet block with the same `id` to section 3b. The self-test reports any part that is missing.
5. Add checks for the new physics to `runSelfTest()` (section 5).

## Notes

- The results table lasts until the page is closed or refreshed. Use Copy or Download CSV to keep readings.
- **Tested in Chrome and Edge** with the network switched off, in light and dark themes:
  - **One screen:** every experiment, in every Compare, Ideal/Realistic and drop-down setting, fits without scrolling at:
    - 1366×768 (laptop, full screen)
    - 1366×657 (laptop, with the browser toolbars showing)
    - 1920×1080 (projector, full screen)
    - 1920×969 (projector, with the browser toolbars showing)
  - **Worksheets:** every experiment's worksheet and answer key was printed to PDF and checked for page breaks, footers and page counts.
